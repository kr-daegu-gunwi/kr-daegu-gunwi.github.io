# 군위군 · 대구광역시

> 군위군 지역 정보 랜딩 사이트

## 🌐 랜딩 페이지

### **https://kr-daegu-gunwi.github.io/**

군위군은 승려 일연이 《삼국유사》를 완성하고 입적한 인각사가 자리한 '삼국유사의 고장'으로 널리 알려진 대구광역시의 유일한 군(郡) 지역이다. 2023년 7월 1일 경상북도에서 대구광역시로 편입되며 대구의 최북단을 이루게 되었고, 군위읍을 중심으로 1읍 7면의 넓은 농촌형 행정구역을 유지하고 있다. 남동쪽으로는 해발 1,193m의 팔공산이 우뚝 솟아 있고 그 자락 절벽에는 '제2석굴암'으로 불려 온 국보 아미타여래삼존 석굴이 안치되어, 대구에서 유일한 국보를 품은 고장이 되었다. 1938년 문을 연 화본역과 부계면 대율리 한밤마을 돌담길, 영화 《리틀 포레스트》 촬영지 등 옛 정취가 살아 있는 명소가 많아 조용한 힐링 여행지로 사랑받는다. 사과와 자두를 비롯한 과수 농업이 발달한 청정 산간 지역이자, 대구경북통합신공항 건설과 삼국유사 체류형 관광거점 조성으로 새로운 전기를 맞고 있는 곳이다.
